evrptw_to_multi_depot(instance, num_depots=2) in data_generation.py
Behavior: Converts a single-depot EVRPTW instance to multi-depot by changing the instance in place and returning it.
Depot layout: The original depot stays at index 0. Extra depots are added at the end of the node list. Their positions are fixed (no randomness):
Bounding box of all nodes is computed.
Centroid (cx, cy) and radius 0.4 * max(range_x, range_y) are computed.
The num_depots - 1 new depots are placed on the circle around the centroid at angles 2π * k / (num_depots - 1) for k = 0, 1, ....


using serial because in this: Evolving_routing_policies_for_electric_vehicles_by.pdf it got the best results

Start:  Create a list of all unvisited customers.
        pre-calculate distance to nearest station for all nodes
Main Loop (until all customers are visited):
    Get a New Truck: Start a new empty route at the Depot.
    Route Building Loop (While truck can still work):

        Identify Candidates: For all unvisited customers.
            Filter: Ignore customers who are too heavy for the current truck.
            Try Direct Move
                Filter: Ignore customers who are too far for the current time.
                
            If Direct fails, Try Via Station
                Find station minimizing detour
                check battery, charging time
                Filter: Ignore customers who are too far for the current time.

        Check for End of Route:
            If no customers fit, or if the battery is low, drive the truck back to the Depot (recharging on the way if needed).
            Stop this route and go back to get a new truck.

        Score Candidates:
            For every valid customer, calculate a Score.
            Pick the customer with the best score.

        Execute Move:
            Drive to that customer. (If the battery is too low to reach them directly, insert a visit to a Charging Station first).
            Add the customer to the route.
            Update the truck's remaining load and battery.
            Mark the customer as "Visited."

Finish: Return the list of all completed routes.




FUNCTION run_genetic_programming(instances, pop_size, gens):

    INITIALIZE population, statistics, hall_of_fame
    EVALUATE fitness of initial population
    UPDATE hall_of_fame

    FOR gen = 1 TO gens:
        # 1. Selection & Variation
        offspring = TOURNAMENT_SELECT(population, size=pop_size)
        APPLY CROSSOVER to offspring (Prob=0.5)
        APPLY MUTATION to offspring (Prob=0.1)

        # 2. Evaluation
        EVALUATE individuals in offspring with new genomes

        # 3. Survival (Mu + Lambda Elitism)
        UPDATE hall_of_fame with offspring
        # Keep the absolute best N individuals from both parents and children
        population = SELECT_BEST(population + offspring, size=pop_size)

        LOG statistics for gen

    RETURN hall_of_fame[0] (Best individual found)
